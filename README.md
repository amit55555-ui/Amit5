# שעון נוכחות

אפליקציית נוכחות לעובדים. כל עובד נכנס עם משתמש וסיסמה משלו ומדווח כניסה, יציאה והפסקות.
המנהל מקבל דוח חודשי לכל העובדים, עם שעות נוספות ושכר משוער.

- **עובדים:** `/` — כניסה, יציאה, הפסקה, סיכום שבועי וחודשי.
- **מנהל:** `/admin` — דוח נוכחות, ניהול עובדים, הגדרות. כניסה עם סיסמת מנהל.

## הפעלה מקומית

```bash
npm install
npm run dev
```

פתחו <http://localhost:3000/admin>. סיסמת המנהל ההתחלתית היא **1234** (החליפו אותה מיד בלשונית "הגדרות").
בלי מסד נתונים, הנתונים נשמרים בקובץ זמני. זה מתאים רק לניסיון.

## העלאה לאוויר (Vercel + Neon), בערך 10 דקות

1. ב-<https://vercel.com>: **Add New → Project**, ובחרו את הריפו `attendance`. לחצו **Deploy**.
2. בפרויקט שנוצר: **Storage → Create Database → Neon (Postgres)**, וחברו אותו לפרויקט.
   Vercel יוסיף לבד את המשתנה `DATABASE_URL`. הטבלאות נוצרות אוטומטית בשימוש הראשון.
3. ב-**Settings → Environment Variables** הוסיפו:

   | משתנה | מה לשים |
   |-------|---------|
   | `SESSION_SECRET` | לא חובה. מחרוזת אקראית ארוכה לחתימת ההתחברות. בלי זה המפתח נגזר אוטומטית מחיבור מסד הנתונים. |
   | `ADMIN_PASSWORD` | סיסמת מנהל התחלתית (לא חובה; בלי זה הסיסמה היא 1234 עד שתחליפו). |

4. **Deployments → Redeploy**, כדי שהמשתנים ייכנסו לתוקף.
5. היכנסו ל-`/admin`, החליפו סיסמה, הגדירו את העסק והוסיפו עובדים.
   שלחו לכל עובד את הכתובת, את שם המשתמש ואת הסיסמה שלו.

## מה יש בממשק המנהל

- **דוח נוכחות:** מי במשמרת עכשיו, וסיכום חודשי לכל עובד (ימים, שעות, נוספות 125%/150%, שכר משוער).
  לחיצה על עובד מציגה את כל המשמרות שלו, ושם אפשר לתקן, להוסיף או למחוק משמרת.
  יש ייצוא לאקסל (CSV) בשתי צורות: סיכום, ופירוט של כל המשמרות.
- **סידור משמרות:** תצוגה שבועית (ראשון–שבת) עם שעות הפעילות של כל יום. שיבוץ עובד בלחיצה, עם קיצורים
  (יום מלא, בוקר, ערב), פס זמן שמראה מי עובד מתי, והתראה על שעות שלא מאוישות.
  אפשר להעתיק את הסידור מהשבוע הקודם ולייצא לאקסל. העובדים רואים את המשמרות שלהם בלשונית "הסידור שלי".
  שעות הפעילות (ברירת מחדל: א׳–ה׳ 09:00–21:00, ו׳ 09:00–13:30, שבת סגור) משתנות בהגדרות.
- **עובדים:** הוספה, עריכה, איפוס סיסמה, שכר לשעה, דמי נסיעה, השבתה ומחיקה.
- **הגדרות:** שם העסק, שעות תקן ליום, אחוזי שעות נוספות, דמי נסיעה, האם עובדים יכולים לתקן משמרות בעצמם,
  האם עובדים רואים את השכר שלהם, והחלפת סיסמת מנהל.

## אבטחה

- הסיסמאות נשמרות מוצפנות (scrypt), ואף אחד לא יכול לראות אותן, גם לא המנהל.
- החלפת סיסמה לעובד מנתקת אותו מכל המכשירים.
- כל התאריכים והשעות מחושבים לפי שעון ישראל.
